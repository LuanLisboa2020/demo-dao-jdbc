# 🗄️ Demo DAO JDBC

Projeto desenvolvido em Java para estudo do padrão DAO (Data Access Object) utilizando JDBC puro para acesso a banco de dados relacional.

O objetivo é demonstrar operações básicas de persistência diretamente via JDBC, aplicando boas práticas de separação de responsabilidades.

---

## 🚀 Tecnologias Utilizadas

- Java 21
- JDBC
- MySQL
- Maven

---

## 📚 Conceitos Aplicados

- Padrão DAO
- Conexão com banco via DriverManager
- PreparedStatement
- ResultSet
- Tratamento de exceções
- Separação entre camada de acesso a dados e regra de negócio

---

## 🏗 Estrutura do Projeto

- model
- dao
- db
- application

---

## ▶ Como Executar

1. Configurar banco de dados MySQL
2. Ajustar dados de conexão na classe de configuração
3. Executar a aplicação
